  • Validated payment, review, product and delivery relationships with cross-table checks

01.

Overall revenue and order scale

QUERY / ANALYSIS
SELECT
    ROUND(SUM(p.payment_value), 2) AS total_revenue,
    COUNT(DISTINCT o.order_id) AS total_orders,
    ROUND(SUM(p.payment_value) / COUNT(DISTINCT o.order_id), 2) AS average_order_value
FROM orders o
JOIN payments p ON p.order_id = o.order_id
WHERE o.order_status = 'Delivered';
INSIGHT

The delivered-order analysis reports about R$15.42M in payment value across 96,478 delivered orders, giving an AOV of about R$159.86.

02.

Revenue growth and the strongest period

QUERY / ANALYSIS
SELECT
    DATE_FORMAT(o.order_purchase_timestamp, '%Y-%m') AS month,
    ROUND(SUM(p.payment_value), 2) AS monthly_revenue,
    COUNT(DISTINCT o.order_id) AS orders
FROM orders o
JOIN payments p ON o.order_id = p.order_id
WHERE o.order_status = 'Delivered'
GROUP BY DATE_FORMAT(o.order_purchase_timestamp, '%Y-%m')
ORDER BY month;
INSIGHT

Revenue is strongly seasonal. November 2017 is the standout period in the project, with monthly revenue above R$1.15M and the highest order volume.

03.

Which product categories drive the most revenue?

QUERY / ANALYSIS
SELECT
    pc.product_category_english AS product_category,
    ROUND(SUM(i.price + i.freight_value), 2) AS revenue_generated
FROM products p
JOIN items i ON i.product_id = p.product_id
JOIN product_category pc ON p.category_name = pc.product_category
JOIN orders o ON o.order_id = i.order_id
WHERE o.order_status = 'Delivered'
GROUP BY pc.product_category_english
ORDER BY revenue_generated DESC;
INSIGHT

Revenue is concentrated in a smaller group of categories, led by Watches & Gifts and Health & Beauty in the project analysis. Those categories deserve closer assortment and merchandising attention.

04.

Which individual products are the strongest revenue generators?

QUERY / ANALYSIS
SELECT
    p.product_id,
    pc.product_category_english AS product_category,
    ROUND(SUM(i.price), 2) AS revenue,
    COUNT(*) AS units_sold
FROM items i
JOIN products p ON p.product_id = i.product_id
JOIN product_category pc ON pc.product_category = p.category_name
JOIN orders o ON o.order_id = i.order_id
WHERE o.order_status = 'Delivered'
GROUP BY p.product_id, pc.product_category_english
ORDER BY revenue DESC
LIMIT 10;
INSIGHT

The analysis identifies a small set of products with outsized revenue contribution. Product-level concentration helps prioritize inventory and seller attention.

05.

How strong is customer retention and repeat purchasing?

QUERY / ANALYSIS
WITH customer_orders AS (
    SELECT c.customer_unique_id,
           COUNT(DISTINCT o.order_id) AS order_count
    FROM customers c
    JOIN orders o ON c.customer_id = o.customer_id
    WHERE o.order_status = 'Delivered'
    GROUP BY c.customer_unique_id
)
SELECT
    CASE WHEN order_count = 1 THEN 'One-time' ELSE 'Repeat' END AS customer_type,
    COUNT(*) AS customers
FROM customer_orders
GROUP BY customer_type;
INSIGHT

Repeat purchasing is a weak point. The project also identifies only 471 customers ordering in back-to-back months, making retention a major growth opportunity.

06.

Which customers have the highest lifetime value?

QUERY / ANALYSIS
SELECT
    c.customer_unique_id,
    ROUND(SUM(p.payment_value), 2) AS total_purchase,
    COUNT(DISTINCT o.order_id) AS orders
FROM customers c
JOIN orders o ON o.customer_id = c.customer_id
JOIN payments p ON o.order_id = p.order_id
WHERE o.order_status = 'Delivered'
GROUP BY c.customer_unique_id
ORDER BY total_purchase DESC
LIMIT 10;
INSIGHT

Customer value is highly uneven: a small group of customers contributes disproportionately high lifetime purchase value and should be protected with retention-focused activity.

07.

Which RFM segments contain the most valuable customers?

QUERY / ANALYSIS
WITH rfm AS (
    SELECT c.customer_unique_id,
           TIMESTAMPDIFF(DAY, MAX(o.order_purchase_timestamp), '2018-10-17 17:30:00') AS recency,
           COUNT(DISTINCT o.order_id) AS frequency,
           SUM(i.price + i.freight_value) AS monetary
    FROM orders o
    JOIN customers c ON o.customer_id = c.customer_id
    JOIN items i ON i.order_id = o.order_id
    WHERE o.order_status = 'Delivered'
    GROUP BY c.customer_unique_id
)
SELECT * FROM rfm
ORDER BY monetary DESC;
INSIGHT

RFM analysis separates recent, frequent and high-spend customers so retention effort can focus on the segments with the greatest economic value.

08.

Which geographies generate the most revenue?

QUERY / ANALYSIS
SELECT
    s.seller_city AS city,
    ROUND(SUM(i.price), 2) AS total_revenue
FROM items i
JOIN sellers s ON s.seller_id = i.seller_id
JOIN orders o ON o.order_id = i.order_id
WHERE o.order_status = 'Delivered'
GROUP BY s.seller_city

LIMIT 10;
INSIGHT

São Paulo dominates the project geography analysis, showing that marketplace value is concentrated in major locations and that regional performance should not be treated as uniform.

09.

How much delivery friction exists?

QUERY / ANALYSIS
SELECT
    COUNT(*) AS delayed_orders_count,
    (SELECT COUNT(*) FROM orders WHERE order_status = 'Delivered') AS total_orders,
    ROUND(100 * COUNT(*) / (SELECT COUNT(*) FROM orders WHERE order_status = 'Delivered'), 2) AS delayed_percentage
FROM orders
WHERE order_status = 'Delivered'
  AND order_delivered_customer_date > order_estimated_delivery_date;
INSIGHT

About 8.11% of delivered orders were later than the estimated delivery date. Delivery reliability is therefore a measurable operational lever.

10.

Which states show the longest delivery times?

QUERY / ANALYSIS
SELECT
    s.seller_state AS state,
    ROUND(AVG(TIMESTAMPDIFF(DAY, o.order_delivered_carrier_date, o.order_delivered_customer_date)), 2) AS avg_shipping_days
FROM items i
JOIN sellers s ON i.seller_id = s.seller_id
JOIN orders o ON o.order_id = i.order_id
WHERE o.order_approved_at < o.order_delivered_customer_date
  AND o.order_status = 'Delivered'
GROUP BY s.seller_state
ORDER BY avg_shipping_days DESC
LIMIT 5;
INSIGHT

Delivery time differs sharply by state. The analysis highlights Amazonas as an extreme case, showing where logistics partnerships or fulfillment strategy could have the greatest impact.

14.

How does product size relate to freight cost?

QUERY / ANALYSIS
SELECT
    CASE
        WHEN (p.length_cm * p.width_cm * p.height_cm) < 500 THEN 'Small'
        WHEN (p.length_cm * p.width_cm * p.height_cm) < 2000 THEN 'Medium'
        ELSE 'Large'
    END AS product_size,
    ROUND(AVG(i.freight_value), 2) AS avg_freight_value,
    COUNT(*) AS total_items
FROM products p
JOIN items i ON p.product_id = i.product_id
GROUP BY product_size
ORDER BY avg_freight_value;
INSIGHT

Freight cost varies with product characteristics. Small and medium products show similar average freight in the project, while larger items create more obvious logistics pressure.

16.

How does revenue change month over month?

QUERY / ANALYSIS
WITH value AS (
    SELECT DATE_FORMAT(o.order_purchase_timestamp, '%Y-%m-01') AS month_year,
           ROUND(SUM(i.price), 2) AS revenue
    FROM orders o
    JOIN items i ON o.order_id = i.order_id
    WHERE o.order_purchase_timestamp > '2017-01-01'
    GROUP BY DATE_FORMAT(o.order_purchase_timestamp, '%Y-%m-01')
)
SELECT month_year, revenue,
       LAG(revenue) OVER (ORDER BY month_year) AS previous_month_revenue,
       ROUND((revenue - LAG(revenue) OVER (ORDER BY month_year)) / LAG(revenue) OVER (ORDER BY month_year) * 100, 2) AS mom_growth_percent
FROM value;
INSIGHT

The project excludes inconsistent 2016 data for this comparison and uses month-over-month growth to make the later trend easier to interpret.

17.

What is the cumulative revenue trajectory?

QUERY / ANALYSIS
WITH revenue AS (
    SELECT DATE_FORMAT(o.order_purchase_timestamp, '%Y-%m-01') AS month_year,
           SUM(i.price) AS total_revenue
    FROM orders o
    JOIN items i ON i.order_id = o.order_id
    GROUP BY DATE_FORMAT(o.order_purchase_timestamp, '%Y-%m-01')
)
SELECT month_year, total_revenue,
       SUM(total_revenue) OVER (ORDER BY month_year) AS running_total
FROM revenue;
INSIGHT

A running total shows how individual monthly performance compounds into the marketplace’s overall revenue trajectory.

18.

What does cohort retention reveal?

QUERY / ANALYSIS
WITH first_purchase AS (
    SELECT c.customer_unique_id, MIN(o.order_purchase_timestamp) AS first_purchase
    FROM orders o
    JOIN customers c ON c.customer_id = o.customer_id
    WHERE o.order_status = 'Delivered'
    GROUP BY c.customer_unique_id
), cohort AS (
    SELECT c.customer_unique_id, DATE_FORMAT(fp.first_purchase, '%Y-%m-01') AS cohort_month,
           DATE_FORMAT(o.order_purchase_timestamp, '%Y-%m-01') AS purchase_month
    FROM customers c
    JOIN first_purchase fp ON c.customer_unique_id = fp.customer_unique_id
    JOIN orders o ON o.customer_id = c.customer_id
    WHERE o.order_status = 'Delivered'
)
SELECT cohort_month, purchase_month, COUNT(DISTINCT customer_unique_id) AS customers
FROM cohort
GROUP BY cohort_month, purchase_month
ORDER BY cohort_month, purchase_month;
INSIGHT

Cohort analysis reinforces the retention problem by showing how quickly customers disappear after their first purchase.

OVERALL INSIGHTS

Overall Business Insights

The analysis points to four connected priorities: protect revenue drivers, improve repeat purchasing, reduce delivery friction, and focus seller and assortment decisions on measurable customer value.

Revenue is concentrated

A relatively small set of categories, products, customers and locations drives a large share of marketplace value.

Retention is the biggest growth opportunity

Strong one-time transaction volume is not matched by equally strong repeat purchasing, making customer reactivation and loyalty important.

Logistics affects the customer experience

Delivery delays and large state-level differences show that fulfillment reliability is a practical lever for satisfaction and marketplace performance.

Seller quality matters beyond sales

Combining seller reach, revenue and review outcomes gives a more useful view of marketplace health than revenue alone.

CONCLUSION

What the project tells us

The Olist analysis shows a marketplace with strong transaction scale but clear opportunities to improve the quality of that growth. Revenue is concentrated in specific categories, products, customers and geographies, while repeat purchasing remains comparatively weak. At the same time, delivery delays and regional logistics differences create avoidable friction. The strongest business response is therefore to protect high-value customers, build repeat-purchase behavior, improve fulfillment reliability and prioritize the sellers and products that consistently create both commercial value and positive customer outcomes.
