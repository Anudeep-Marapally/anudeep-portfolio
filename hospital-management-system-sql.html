01.

What is the overall appointment workload and status mix?

QUERY / ANALYSIS
SELECT status, COUNT(*) AS appointment_count
FROM appointments
GROUP BY status
ORDER BY appointment_count DESC;
INSIGHT

Appointment status provides the first operational view of hospital workload and helps separate completed care from pending or cancelled activity.

02.

Which doctors handle the largest patient workload?

QUERY / ANALYSIS
SELECT d.doctor_id, d.first_name, d.last_name,
       COUNT(a.appointment_id) AS appointments
FROM doctors d
JOIN appointments a ON d.doctor_id=a.doctor_id
GROUP BY d.doctor_id,d.first_name,d.last_name
ORDER BY appointments DESC;
INSIGHT

Doctor-level workload identifies concentration of appointments and supports staffing and scheduling decisions.

03.

Which specializations receive the most appointments?

QUERY / ANALYSIS
SELECT d.specialization, COUNT(*) AS appointment_count
FROM doctors d
JOIN appointments a ON d.doctor_id=a.doctor_id
GROUP BY d.specialization
ORDER BY appointment_count DESC;
INSIGHT

Specialization demand helps show where clinical capacity is most heavily utilized.

04.

Which treatments generate the most billing value?

QUERY / ANALYSIS
SELECT t.treatment_type,
       COUNT(*) AS treatment_count,
       ROUND(SUM(t.cost),2) AS treatment_value
FROM treatments t
GROUP BY t.treatment_type
ORDER BY treatment_value DESC;
INSIGHT

Treatment-level revenue analysis connects clinical activity with financial value and highlights the services with the largest contribution.

05.

Which payment methods dominate hospital billing?

QUERY / ANALYSIS
SELECT payment_method, COUNT(*) AS bills,
       ROUND(SUM(amount),2) AS billed_amount
FROM billing
GROUP BY payment_method
ORDER BY billed_amount DESC;
INSIGHT

Payment mix helps explain how patients settle bills and where payment operations are concentrated.

06.

How does billing value change over time?

QUERY / ANALYSIS
SELECT month, ROUND(SUM(amount),2) AS monthly_billing
FROM billing
GROUP BY month
ORDER BY monthly_billing DESC;
INSIGHT

Monthly billing provides a simple view of financial activity and helps identify periods of higher hospital utilization.

07.

What should management focus on operationally?

QUERY / ANALYSIS
SELECT d.specialization, COUNT(a.appointment_id) AS appointments,
       ROUND(AVG(t.cost),2) AS avg_treatment_cost
FROM doctors d
JOIN appointments a ON d.doctor_id=a.doctor_id
JOIN treatments t ON t.appointment_id=a.appointment_id
GROUP BY d.specialization
ORDER BY appointments DESC;
INSIGHT

The combined view of appointment demand and treatment value helps management prioritize capacity, scheduling and service-level decisions.

CONCLUSION

What the project tells us

The hospital project demonstrates how a well-structured relational database can support practical management decisions. Appointment workload, specialization demand and treatment billing reveal where operational attention is concentrated, while payment and time-based analysis add financial context. The key takeaway is that hospital performance should be managed by connecting capacity and clinical demand with financial outcomes rather than viewing each metric in isolation.
